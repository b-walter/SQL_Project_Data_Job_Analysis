# The Analysis
Each question in this project aimed to expose specific information from the job market dataset. Here are the queries I used and what I discovered from each one:

### 1. Top Paying Remote Data Analyst Jobs
To find these jobs, I selected columns from two tables using a LEFT JOIN. I filtered for data analyst roles and remote locations, and excluded postings that did not have a salary listed. This query highlights the highest potential opportunities for data analysts.

```sql
SELECT
    job_id,
    job_title,
    job_location,
    job_schedule_type,
    salary_year_avg,
    job_posted_date,
    name AS comany_name
FROM
    job_postings_fact
LEFT JOIN
    company_dim ON job_postings_fact.company_id = company_dim.company_id
WHERE
    job_title_short = 'Data Analyst' AND
    job_location = 'Anywhere' AND
    salary_year_avg IS NOT NULL
ORDER BY
    salary_year_avg DESC
LIMIT 10;
```
My insights from this query:
- **Salray Range:** Looking at the 10 highest paying data analyst roles, there was a wide range of salaries from $184,000 to $650,000. This shows a significant salary potential for the field.
- **Employers:** These jobs were spread across multiple different industries, including companies such as SmartAsset, Meta, and AT&T.
- **Job Titles:** Within these data analyst roles, there was a high diversity of job titles. This shows the variety of positions and specialized skills within the data analytics field.

### 2. Skills for Top Remote Data Analyst Jobs
For this question, I used the previous query as a CTE and removed three columns from the SELECT statement that were no longer needed. I then joined the CTE with two other tables to find the skills associated with the jobs from the first query. This tells us what skills are needed to compete for those top paying jobs.

```sql
WITH top_paying_jobs AS (
    SELECT
        job_id,
        job_title,
        salary_year_avg,
        name AS company_name
    FROM
        job_postings_fact
    LEFT JOIN
        company_dim ON job_postings_fact.company_id = company_dim.company_id
    WHERE
        job_title_short = 'Data Analyst' AND
        job_location = 'Anywhere' AND
        salary_year_avg IS NOT NULL
    ORDER BY
        salary_year_avg DESC
    LIMIT 10
)

SELECT
    top_paying_jobs.*,
    skills
FROM top_paying_jobs
INNER JOIN skills_job_dim ON top_paying_jobs.job_id = skills_job_dim.job_id
INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
ORDER BY
    salary_year_avg DESC;
```
My insights from this query:
- **Top Skills:** The top 3 required skills for these jobs are SQL, Python, and Tableau, appearing in eight, seven, and six roles respectively.
- **Other Relevant Skills:** R, Excel, Pandas, Snowflake and cloud technologies also appear across mulitple roles, highlighting the value of a broader modern analytics skillset.

### 3. Highest Skills In Demand for Data Analysts
To answer this question, I wrote  query to return the top five skills and the number of times they appear in remote data analyst roles. This tells us what skills are most commonly required for data analysts in general, not only the top ten jobs.

```sql
SELECT
    skills,
    COUNT(skills_job_dim.job_id) AS demand_count
FROM job_postings_fact
INNER JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id
INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
WHERE
    job_title_short = 'Data Analyst' AND
    job_work_from_home = True
GROUP BY
    skills
ORDER BY
    demand_count DESC
LIMIT 5;
```
My insights from this query:
- **Top Skill:** SQL is safely the highest skill in demand for data analysts, showing 2,680 times more in job postings than the second highest skill.
- **Other Top Skills:** Excel and Python are very close together at second and third, respectively. Spreadsheet and programming skills are highly required for data analysts.
- **Data Visualization:** Tableau and Power BI finish the top five at fourth and fifth, respectively. Being able to tell a story with clean visuals is another skill all data analysts need to add to their toolbox.

### 4. Top Skills Based on Salary
This query looks at the top data analyst skills based on the highest average salaries. If you are looking to secure a higher salary as a data analyst, these are the skills you want to have.

```sql
SELECT
    skills,
    ROUND(AVG(salary_year_avg), 0) AS avg_salary
FROM job_postings_fact
INNER JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id
INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
WHERE
    job_title_short = 'Data Analyst'
    AND salary_year_avg IS NOT NULL
    AND job_work_from_home = True
GROUP BY
    skills
ORDER BY
    avg_salary DESC
LIMIT 25;
```
My insights from this query:
- **PySpark Leads:** With an average salary of $208,172, PySpark proves to be a top skill for for a high paying data analyst role.
- **A High Second:** Bitbucket also shows to be a top skill at $189,155, being closer to the number one spot than to number three.
- **Other Top Skills:** Specialized technical skills command strong salaries as well, including data infrastructure, development, and machine-learning tools.

### 5. Most Optimal Skills to Learn
In this final query, the goal was to check for optimization. I filtered for remote data analyst jobs with listed salaries and required the skill to have at least ten appearances throughout the dataset. This query was sorted by the average salary and the demand count, prioritizing the average salary first.

```sql
SELECT
    skills_dim.skill_id,
    skills_dim.skills,
    COUNT(skills_job_dim.job_id) AS demand_count,
    ROUND(AVG(job_postings_fact.salary_year_avg), 0) AS avg_salary
FROM job_postings_fact
INNER JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id
INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
WHERE
    job_title_short = 'Data Analyst'
    AND salary_year_avg IS NOT NULL
    AND job_work_from_home = True
GROUP BY
    skills_dim.skill_id
HAVING
    COUNT(skills_job_dim.job_id) > 10
ORDER BY
    avg_salary DESC,
    demand_count DESC
LIMIT 25;
```
My insights from this query:
- **Highest Salary:** Go leads the pack when prioritizing for salary. Although it is not the most in demand, it is still one of the higher occuring skills in our job market dataset for higher salaried data analyst roles.
- **Strong Balance:** Snowflake shows to have the highest demand of our top ten skills while maintaining competitive compensation.
- **Cloud & Data Engineering:** In addition to Snowflake, Azure and AWS also demonstrate strong demand and six-figure salaries, highlighting the importance of cloud technologies in data analytics.
- **Final Note:** It is important to note that these results show associations between skills and salaries. This does not guarantee that learning a certain skill will lead to a direct increase in pay.
